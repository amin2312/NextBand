# Beats Per Minute Workflow

## Dependency chain

Analyze user data → Identify user wants → Take action

## user_data

It refers to user data transmitted from smart hardware.

## user_wants

It refers to the wants that users want to define based on their own user data.

## Workflow steps

1. Analyze the user_data.
2. Identify only the actions based on the user_wants. Do not infer or assume any unstated wants.
3. Execute only those requested actions until complete.
4. FINALLY, JUST SAY "ok"
